Eternia Builder

Eternia SMP Builder is a Minecraft Plugin I created that allows for the creation of custom "Builder" blocks that when given a Json file for a build will automatically build the structure in the world. This will be used in the Eternia SMP Minecraft Server to allow for players to easily build structures in their world.

[Java] [Minecraft API] [JSON]

Momir Basic Printer

The Momir Basic Printer is an embedded system designed to allow a user to print a random Magic: The Gathering card from the Momir Basic set. It uses a microcontroller to control a thermal printer and a random number generator to select a card from the set.
